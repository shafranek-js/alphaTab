# Обзор проекта

alphaTab — кроссплатформенная библиотека для чтения, моделирования, отображения и воспроизведения музыкальных партитур и гитарных табулатур.

## Базовая платформа

Ядро написано на TypeScript. Оно включает:

- импорт Guitar Pro 3–8, MusicXML, Capella, MIDI и alphaTex;
- единую объектную модель `Score → Track → Staff → Bar → Voice → Beat → Note`;
- рендеринг стандартной нотации, табулатур, ударных и numbered notation;
- генерацию MIDI и tick lookup;
- синтезатор AlphaSynth с SoundFont2/SoundFont3;
- SVG/Canvas rendering, Web Workers и Audio Worklets;
- экспорт GP7 и alphaTex;
- генерацию C# и Kotlin из общего TypeScript-кода.

## Назначение этого fork

Репозиторий `shafranek-js/alphaTab` развивает официальный alphaTab в сторону самостоятельного обучающего приложения. Главная продуктовая работа сосредоточена в `packages/playground`:

- полноэкранный player UI;
- настройки отображения и треков;
- виртуальная фортепианная клавиатура;
- Web MIDI input;
- Step Practice в режиме ожидания правильной ноты;
- Perform с оценкой ритма и постепенным повышением скорости;
- сохранение партитуры и настроек в `localStorage`;
- визуальные подсказки, Suzuki coloring и кастомизация курсора.

## Продуктовая траектория

На текущем этапе это личный инструмент владельца проекта. Приоритет — практическая польза в собственной музыкальной практике, без необходимости заранее поддерживать массовый продукт, публичный сервис или коммерческую модель.

Рабочая версия приложения при этом публикуется как статический сайт через GitHub Pages. Публичная доступность используется для удобного запуска и проверки текущего состояния, но сама по себе не меняет приоритет с личного инструмента на массовый продукт.

Возможное долгосрочное направление:

- сделать приложение доступным широкой аудитории;
- развить его из персонального инструмента в полноценный обучающий продукт;
- добавить поддержку других музыкальных инструментов, не ограничиваясь фортепиано.

Это направление, а не обязательства текущего этапа. Архитектурные решения желательно принимать без искусственной привязки к одному пользователю или одному инструменту, если такая гибкость не создаёт заметной сложности сейчас.

## Границы

- Playground работает в браузере и не содержит прикладного backend.
- Публичная сборка разворачивается из `develop` по адресу `https://shafranek-js.github.io/alphaTab/`.
- Web MIDI зависит от поддержки браузера и разрешения пользователя.
- Официальная документация описывает базовый alphaTab, но не все функции этого fork.
- Папка `competitors/` локальная, исключена из Git и не является частью поставки.
