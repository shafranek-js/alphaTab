# alphaTab Knowledge Base

Это Obsidian vault с постоянным рабочим контекстом проекта. Откройте папку `knowledge-base` как отдельное хранилище Obsidian.

Начальная страница: [[00 Home]].

Команды обслуживания:

```bash
npm run kb:update
npm run kb:check
```

`kb:update` обновляет снимок Git, CodeGraph, список пакетов и последние коммиты. Файлы в `_generated` нельзя редактировать вручную.
