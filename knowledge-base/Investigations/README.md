# Investigations

Здесь хранятся диагностики и исследования, которые могут понадобиться повторно.

Используйте [[Templates/Investigation]]. После завершения:

- укажите commit/branch и воспроизводимые команды;
- отделите наблюдения от гипотез;
- добавьте ссылки на symbols и tests;
- перенесите долговременные выводы в основную subsystem note;
- если принято решение, создайте запись в [[Decisions/Decision Log]].
